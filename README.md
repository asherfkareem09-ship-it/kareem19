# G SPORT

Static storefront (single index.html). Works on Chrome and Safari, desktop and mobile.

## Publish on GitHub Pages
1. Create a new repository on github.com (for example `gsport`), set to Public.
2. Click "uploading an existing file" and upload everything in this folder (index.html, .nojekyll, README.md). Commit.
3. Open Settings > Pages. Under Source choose "Deploy from a branch", Branch `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at https://YOUR-USERNAME.github.io/gsport/

## What works in this static version
Browsing, per-product cinematic intros, product pages, cart (saved on the device).

## What does not work here
Admin dashboard, order saving and tracking, image upload, and online payment. They need a backend (database, storage, payment server).
